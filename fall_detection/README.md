# V4 Fall Detection

## Overview

This folder contains the V4 implementation of the User Activity Analysis & Image Processing module.

The V4 system combines:

- Raspberry Pi Camera
- Picamera2
- OpenCV
- HOG person detection
- TensorFlow / Keras
- Image enhancement using CLAHE
- Body geometry analysis
- Temporal movement analysis
- Fall-state confirmation
